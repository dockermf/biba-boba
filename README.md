# Мини-биржа игровых предметов

- Пользователи выставляют игровые предметы (не знаю какие и как будут выглядеть -- камешки, палки) на продажу, и покупают их за виртуальную валюту. Реальные деньги не используются.

## Возможности

- Регистрация аккаунта, вход в аккаунт, удаление аккаунта
- Виртуальный баланс (стартовая сумма при регистрации, промокоды, зачисление с админского аккаунта)
- Выставление предмета на продажу (цена, описание, теги) - с тегами подумать -- теги это ближе к фиче поиска, считай категория
- Снятие предмета с продажи
- Покупка предмета (начисление и снятие денег с двух аккаунтов)
- Кейсы за деньги для лудоманов
- Ежедневные бесплатные кейсы с таймером (деньги/предметы внутри) для халявщиков
- История покупок/продаж, баланса
- Витрина твоих шмоток (купленных выбитых) -- может просто в профиле можно посмотреть его инвентарь?
- Поиск пользователей; предметов по тегам/названию

## Идеи на потом

- Аукционы
- Комиссия
- Фильтры в поиске (дата, цена и т.д.)
- Типы аккаунтов (обычный, админ)

## Как это работает

1) Пользователь зарегестрировался и получил стартовую сумму
2) Счетик на ежеденевные кейсы обновились
3) Человек может купить стартовые предметы уже у тех у кого есть или выбить с кейса (купить кейсы)
4) При покупке списать деньги покупателя, начислить деньги продавцу, добавить предмет покупателю и отжать у продавца
