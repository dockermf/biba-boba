# Мини-биржа игровых предметов

- Пользователи выставляют игровые предметы (не знаю какие и как будут выглядеть) на продажу, и покупают их за виртуальную валюту. Реальные деньги не используются.

## Возможности

- Регистрация аккаунта и вход
- Виртуальный баланс (стартовая сумма при регистрации, промокоды, зачисление с админского аккаунта)
- Выставление предмета на продажу (цена, описание, теги) - с тегами подумать
- Снятие предмета на продажу
- Покупка предмета ( начисление и снятие денег с двух аккаунтов)
- Кейсы с ежедневным таймером на деньги или шмотку любую, для лудоманов
- История покупок
- Витрина твоих шмоток (купленных выбитых)

## Идеи на потом

- Аукционы
- Комисия
- Поиск и фильтры по предметам

## Как это работает

1) Пользователь зарегестрировался и получил стартовую сумму
2) счетик на ежеденевные кейсы обновились
3) Человек может купить стартовые предметы уже у тех у кого есть или выбить с кейса (купить кейсы)
4) При покупке списать деньги, начислить деньги тому у кого купили, передать право на владение предмета

## Модели данных

`users` | Пользоваетли | - id, username, password, balance

## Важные моменты

- Баланс не может быть отрицательным
- Предметы один раз нельзя выставлять дважды купить дважды
